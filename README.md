# C++ Earnings Calculator

A C++ console application that calculates hourly, weekly, and annual earnings based on user-provided work and pay information.

## Features

- Calculates gross earnings
- Calculates weekly earnings
- Calculates annual earnings
- Supports overtime calculations
- Estimates deductions based on a user-provided percentage
- Formats monetary values for readability

## Built With

- C++
- Visual Studio

## Purpose

This project was created to practice C++ fundamentals, user input,
conditional logic, calculations, and formatted console output.
